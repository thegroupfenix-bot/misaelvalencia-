# Mapa de cobertura de Sudamérica

`puertos-colombia.svg` usa una base geográfica simplificada de Natural Earth (dominio público), recompuesta para el sitio de GLV Services. Colombia se destaca únicamente para identificar los puertos de referencia: Santa Marta, Barranquilla, Cartagena y Buenaventura.

Fuente geográfica: https://www.naturalearthdata.com/
